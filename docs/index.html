simple_document

A rich document model for Eiffel: Unicode text in blocks, with inline styles and links

Overview

simple_document is one model for every library that reads, shows or writes a rich document. It holds Unicode text in blocks, with inline styles and links. It knows no markup and draws nothing.

Version 0.1.0 is a pre-release. It was made for simple_bible (gap GW-13): commentaries, lexicon entries, dictionary articles and notes. It depends only on EiffelBase. Every class is void-safe, SCOOP-compatible and has contracts.

The Model

Class Responsibility
SIMPLE_DOCUMENT An ordered list of blocks. Gives number_of (a numbered item's number) and plain_text (what Copy gives). Edits with add_*, insert, replace and remove. Each add_* returns the new block's text so its spans can be added at once.
DOC_BLOCK One block: a paragraph, a heading (levels 1 to 3), a bulleted or numbered item or a block quote (depths 1 to 3), a rule, a code block, or a table (a header row, then rows of cells). A code block is shown as typed, its line breaks kept, with no inline spans. A numbered item does not store its number.
DOC_TEXT The characters of one text and the spans over them: bold, italic, small capitals, superscript, code, strikethrough, and links with a target. Spans may overlap. flags_at answers every kind over a character as one set of bits and stretch_end where that set changes, so a renderer walks the text one setting at a time. revision grows with every change, so a view re-measures only what changed.

The text is the source: search, copy and a caret see it as typed.

Installation

Add to your ECF:

<library name="simple_document" location="$SIMPLE_EIFFEL/simple_document/simple_document.ecf"/>

Set the environment variable (one-time setup for all simple_* libraries):

set SIMPLE_EIFFEL=<folder that holds your simple_* libraries>

Usage

local
    doc: SIMPLE_DOCUMENT
    t: DOC_BLOCK
do
    create doc.make
    doc.add_heading (1, "Notes").do_nothing
    doc.add_paragraph ("For God so loved the world").add_link (1, 26, "John 3:16")
    t := doc.add_table (<<"Word", "Gloss">>)
    t.add_row (<<"bara", "create">>)
    print (doc.plain_text)
end

Who Uses It

  • simple_markdown reads Markdown into a document and writes one back out.
  • simple_widgets shows and edits one (SW_DOCUMENT_VIEW).
  • A host builds one from other sources (simple_bible: a commentary's HTML).
